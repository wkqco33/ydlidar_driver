# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability or sensitive data leak in this repository:

1. **Do NOT open a public GitHub Issue.**
2. Please report the issue privately by emailing the maintainer at `wkqco33@gmail.com` with the subject tag `[SECURITY] ydlidar_driver`.
3. Include detailed steps to reproduce the vulnerability, along with potential impact.
4. You will receive an initial response acknowledging the report within 48 hours.
5. A patch and advisory will be coordinated before public disclosure.

We appreciate your responsible disclosure!
